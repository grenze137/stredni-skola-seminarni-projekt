## O projektu
Tato středoškolská seminární práce ze semináře z fyziky se zabývá měřením a analýzou tíhové síly a tíhového zrychlení ($g$) ve virtuálním prostředí hry **Minecraft**. 

Cílem práce bylo zjistit, zda se volný pád v Minecraftu řídí reálnými fyzikálními zákony, změřit tíhové zrychlení pomocí redstonových obvodů a command bloků a porovnat výsledky s reálným světem.

### Klíčové výsledky:
- **Experimentální měření:** Čas pádu byl měřen pomocí rychlosti propadávání předmětů (mrkví) v redstonovém okruhu s hoppery.
- **Statistická analýza:** Naměřená data byla fitována třemi teoretickými modely (volný pád, Stokesův model, Newtonův kvadratický model odporu vzduchu).
- **Závěr:** Virtuální svět Minecraftu nejlépe odpovídá **Newtonovu modelu s odporovým členem**, přičemž vypočítané tíhové zrychlení odpovídá přibližně $16{,}09 \text{ m}\cdot\text{s}^{-2}$ (tedy vyšší gravitaci než na Zemi).
